# COD 算力 App 上线预审

审查日期：2026-08-15

审查范围：`/compute` 上线准备版、Expo iOS/Android 容器、算力商品与下单相关前端流程。

## 结论

当前状态：**可用于内部联调，不建议直接提交 App Store 或应用商店审核。**

纯展示版 `/compute/showcase/` 可以作为公开产品展示入口。上线准备版 `/compute/` 的界面、移动适配和安全基线基本成形，但订单、托管、个人资源和经营数据仍有前端演示数据，尚未形成可审计的真实业务闭环。

## 本轮已通过

- Web 类型检查、ESLint、生产构建全部通过。
- Web 自动化测试 149 项通过。
- 移动端自动化测试 35 项通过，Expo Doctor 20/20 检查通过。
- iOS、Android、Web 与 Expo DOM 全平台导出成功，严格 DOM 发布文档校验通过。
- 生产依赖无 high/critical 漏洞；移动工具链仅保留两项已绑定缓解措施、须在 2026-09-11 前复审的既有例外。
- 真实 GPU 产品图已按型号拆分并统一为白底展示。
- 移动端内部滚动容器已恢复 `overflow-y: auto`、`touch-action: pan-y` 和惯性滚动。
- 原生 WebView 已开启滚动，避免 iOS/Android 容器吞掉纵向滑动。
- iOS `buildNumber` 与 Android `versionCode` 已显式声明。
- 会话令牌使用 Secure Store，后台切换时有隐私遮罩。
- 原生桥接使用能力令牌校验，WebView 导航执行来源白名单与失败关闭策略。
- Android 已关闭备份，并阻止外部存储和悬浮窗权限。
- Web 入口包含 CSP、HSTS、点击劫持和权限策略防护。

## 上线阻断项

### P0 真实交易链路

- 商品配置后的提交仅写入 React 本地状态，并生成 `COD-NEW-*` 编号，刷新后丢失。
- 托管申请仅在前端生成 `HT-0814-026`，没有服务端持久化、幂等键、审计日志和失败补偿。
- 上线条件：订单与托管申请接入正式 API，服务端校验库存、价格、账户、权限和幂等性；前端覆盖加载、失败、重试与重复提交。

### P0 演示数据隔离

- `mineOrders`、经营看板、通知、库存、设备、卡时流水和部分状态仍来自静态数据。
- 上线条件：上线准备版全部改为服务端数据；空数据时显示真实空状态；演示数据只保留在 `/compute/showcase/`。

### P0 隐私与商店资料

- 仓库内未发现隐私政策、用户协议、支持网址、数据收集说明、账号注销说明和商店元数据配置。
- 上线条件：补齐公开可访问的隐私政策与用户协议；完成 Apple Privacy Nutrition Label、Google Play Data Safety；提供应用内账号注销入口及支持联系方式。

### P0 图片商业授权

- 当前真实产品图来自第三方产品媒体，素材清单已记录来源，但商业使用授权尚未确认。
- 上线条件：改用 NVIDIA 或供应商书面授权素材，或取得现有素材的商业许可并留档。

## 上线前高优先级项

### P1 发布与签名

- 未发现 EAS Build/Submit 配置、商店签名流程、发布渠道和回滚说明。
- 建议：建立 development、preview、production 三套 profile；版本号由 CI 单向递增；保存可验证的构建产物与回滚版本。

### P1 可观测性

- 未发现移动端崩溃上报、API 错误追踪和订单链路指标。
- 建议：覆盖启动失败、登录失败、下单失败、支付/卡时异常、WebView 白屏和原生桥接失败，避免采集提示词与令牌正文。

### P1 性能

- Web 主脚本约 719 kB，构建提示单包超过 500 kB。
- 建议：将工作区、算力市场和管理页按路由拆包；记录中端 Android 冷启动、首屏和内存基线。

### P1 真机兼容

- 本轮完成浏览器 390×844 视口滚动验证，尚缺 iPhone、iPad 和 Android 真机回归。
- 建议至少覆盖 iOS 当前版与前一主版本、Android 10/12/14、小屏设备、刘海屏、软键盘、深色模式、弱网和横竖屏策略。

## 发布门禁

只有以下条件全部满足，才建议提交商店审核：

1. P0 项全部关闭并有测试证据。
2. 正式 API 环境完成订单、托管、登录、注销与异常恢复验收。
3. 图片授权、隐私政策、用户协议和数据收集声明完成法务确认。
4. iOS 与 Android 正式签名包通过真机冒烟和回归测试。
5. 崩溃、错误率和关键业务指标已接入监控，并完成回滚演练。
