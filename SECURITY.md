# Security Policy

## Reporting a vulnerability

Please do not open a public GitHub issue for suspected security vulnerabilities.

Report security issues privately to `support@kai.com` with:

- affected component and version/commit;
- reproduction steps or proof of concept;
- expected impact;
- any suggested mitigation.

Do not include real user data, production credentials, or third-party secrets in reports.

## Secrets

COD is designed so production credentials remain outside Git. Never commit API keys, access tokens, signing keys, payment credentials, environment files containing secrets, or user data.
