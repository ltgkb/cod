# Contributing to COD

Thanks for your interest in COD.

## Development

1. Fork the repository and create a feature branch.
2. Install dependencies with `npm install`.
3. Run `npm run typecheck`, `npm test`, and `npm run build` before opening a pull request.
4. Keep pull requests focused and explain user-visible behavior changes.
5. Do not commit API keys, credentials, private certificates, production environment files, or user data.

## Issues

Use GitHub Issues for reproducible bugs, feature proposals, and integration requests. Include platform/version details and minimal reproduction steps when possible.
